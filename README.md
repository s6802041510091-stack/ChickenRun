# Chicken Run — วิ่งหนีผู้พัน

มินิโปรเจกต์ React Native + TypeScript (TSX), Expo SDK 57 เกมวิ่ง 3 ช่องแบบ 3D ด้วยการขยับตัวจริง ไม่มี backend ฐานข้อมูล บัญชีผู้ใช้ หรือการบันทึกคะแนน ข้อมูลอยู่ในหน่วยความจำเฉพาะรอบปัจจุบัน

## เริ่มเล่น

ต้องใช้ Node.js 22.18+ (แนะนำ Node 24), Android SDK และ development build/APK ของโปรเจกต์ เนื่องจาก WebGPU ไม่ทำงานใน Expo Go

```powershell
cd D:\Mobile-app\ChickenRun
npm install
npx expo run:android
```

หรือใช้ไฟล์ APK ที่สร้างไว้ในโฟลเดอร์หลักของโปรเจกต์บน Android

ทดลองบนคอมพิวเตอร์: `npm run web` ในเบราว์เซอร์ที่รองรับ WebGPU แล้วเลือก **เล่นด้วยปุ่ม** ใช้ ← → เพื่อเปลี่ยนช่อง, Space/↑ เพื่อกระโดด, Esc เพื่อพัก การตรวจการกระโดดจริงต้องทดสอบบนโทรศัพท์ผ่าน APK/development build

## วิธีเล่น

1. กดเริ่ม → เลือกขยับตัวจริง → อนุญาต Motion เมื่อระบบถาม
2. ถือโทรศัพท์แนวตั้งใกล้ลำตัวสองมือในท่าที่จะเล่น ให้นิ่งประมาณครึ่งวินาที แถบตั้งค่าจะเต็ม ต้องถือค่อนข้างตั้ง (ไม่วางจอราบ) Accelerometer จะอ่านแรงโน้มถ่วงรวมประมาณ 1 g ขณะนิ่ง ไม่จำเป็นต้องรอให้เป็น 0 ส่วน Gyroscope ควรใกล้ 0 เมื่อไม่มีการหมุน
3. ลองเอียงและกระโดดในหน้าฝึก ปรับความไวได้ 3 ระดับ ถ้าทิศกลับกันใช้ปุ่มสลับซ้าย–ขวา การเปลี่ยนค่าจะตั้งท่าถือใหม่
4. ค่าเริ่มต้นเอียงประมาณ 8° เพื่อเปลี่ยนช่องหนึ่งครั้ง (เลือกได้ 6°/8°/11°) แล้วกลับมาใกล้กึ่งกลางประมาณ 0.04 วินาทีก่อนเอียงใหม่ การเอียงค้างไม่เปลี่ยนหลายช่อง
5. กระโดดเบา ๆ อยู่กับที่เพื่อข้ามแคมป์ไฟ ถังไม้และคนตัวใหญ่ถือส้อมต้องเปลี่ยนช่อง เก็บเหรียญด้วยการอยู่ในช่องเดียวกับเหรียญ
6. เริ่มเกมผู้พันจะอยู่ไกล เมื่อชนครั้งแรกผู้พันจะวิ่งขึ้นมาประชิด และถ้าชนอีกครั้งจะถูกจับ กดพักได้ตลอด สลับแอปหรือข้อมูลเซ็นเซอร์หยุดส่งจะหยุดเกมให้
7. ตอนจบแสดงเหรียญและระยะทางจำลองในเกม การเริ่มใหม่หรือปิดแอปจะล้างข้อมูล

## จังหวะเกม

- 6 ฉาก: ร้านขายไก่ → หลังร้าน → โรงงาน → ฟาร์มไก่ → ถนน → ภูเขา
- ฉากละ 30 วินาที รวม 3 นาที ความเร็วคงที่ 6 เมตรจำลอง/วินาที ไม่มีการเร่ง
- สิ่งกีดขวางหนึ่งชิ้นต่อแถว ห่างอย่างน้อย 4 วินาที มองเห็นล่วงหน้า 5 วินาที และมีช่องว่างให้หลบเสมอ
- ท้ายแต่ละฉาก 6 วินาทีเป็นช่วงโล่ง การเปลี่ยนช่องหลบได้ทุกสิ่งกีดขวาง จึงไม่บังคับให้ต้องกระโดดต่อเนื่อง
- กระโดดในเกมยาว 1.25 วินาทีเพื่อให้จังหวะผ่อนปรน ไม่ใช่เวลาที่ต้องลอยตัวจริง
- ระยะทางสูงสุด 1,080 เมตร เป็นระยะในเกม ไม่ใช่ GPS หรือระยะออกกำลังกายจริง

## ภาพ 3D

- Three.js WebGPU วาดโมเดลไก่หน้าตกใจ ผู้พันผมขาวกล้ามใหญ่ เหรียญ ถังไม้ แคมป์ไฟ และคนตัวใหญ่ถือส้อมจากรูปทรง low-poly ภายในแอป
- ถนนสามเลน เส้นแบ่งถนน และฉากสองข้างทางเคลื่อนเข้าหากล้องตามเวลาเกม มีฉากร้าน หลังร้าน โรงงาน ฟาร์ม ถนน และภูเขา
- ไก่และผู้พันหันหน้าไปตามทิศวิ่ง ปีก ขา และผู้พันขยับตามจังหวะ ขนไก่แปดชิ้นปลิวด้านหลัง ผู้พันมีตำแหน่งไกลและตำแหน่งไล่ประชิดตามสถานะการชน
- หน้าแรกใช้ภาพปกที่สร้างไว้ ส่วนสนามเปิด WebGPU Canvas เพียงชุดเดียวเพื่อลดการใช้ GPU และหน่วยความจำ

## เซ็นเซอร์

`expo-sensors` ขอข้อมูล Accelerometer และ Gyroscope ทุก 8 ms; อัตราที่ได้รับจริงขึ้นอยู่กับเซ็นเซอร์ของโทรศัพท์

- Accelerometer: ตอนวางนิ่งยังอ่านแรงโน้มถ่วงรวมประมาณ 1 g ไม่ใช่ 0 เกมใช้ขนาดเวกเตอร์ `sqrt(x²+y²+z²)` หน่วย g เพื่อลดผลจากการเอียง ตรวจแรงส่งมากกว่า threshold ตามด้วยแรงต่ำกว่า 0.88 g ภายใน 350 ms แล้วส่ง jump มี cooldown 1.2 วินาทีและต้องกลับมานิ่งเพื่อป้องกันแรงลงพื้นซ้ำ
- Gyroscope: กรองและอินทิเกรตแกน z แล้วผสานกับมุมจากแรงโน้มถ่วงเพื่อลด drift การเอียงเร็วใช้ gyro assist สั่งก่อนถึงมุมเต็ม การคืนสถานะดูจากท่าจริงของโทรศัพท์แทนการรอมุม gyro ที่สะสมกลับเป็นศูนย์ มี latch และช่วงกันซ้ำ 90 ms
- ตั้ง neutral จากค่าท่าถือเฉลี่ย 48 ตัวอย่างที่นิ่ง ปฏิเสธการตั้งค่าขณะเคลื่อนไหวหรือถือจอราบ
- มีการตรวจ availability/permission, timeout เมื่อไม่มีข้อมูล และถอด listener เมื่อพัก/จบ/ออกจากหน้าฝึก

โทรศัพท์วัดการขยับของเครื่อง ไม่สามารถยืนยันว่าผู้เล่นกระโดดจริง การสะบัดแรง ๆ อาจผ่านเงื่อนไขได้ ค่าที่ให้เป็นจุดเริ่มต้นและต้องปรับจากการทดสอบบนเครื่องจริง การเคลื่อนไหวของเกมเป็นสิ่งจำเป็น แต่ปิดการเด้งและโยกตกแต่งเมื่อระบบเปิด Reduce Motion

## โครงสร้าง

```text
App.tsx                       Safe-area provider
src/screens/game.tsx          หน้าหลัก / ฝึก / เล่น / พัก / ผลลัพธ์
src/screens/game-styles.ts     รูปแบบหน้าจอ
src/components/art.tsx         ภาพ SVG สำหรับหน้าฝึกและหน้าผลลัพธ์
src/components/game-scene.tsx  โมเดล สนาม และวงจรภาพ Three.js WebGPU
src/lib/make-webgpu-renderer.ts ตัวเชื่อม Three.js กับ Canvas ของ React Native
src/game/engine.ts             สนาม การชน เหรียญ และความคืบหน้า
src/game/motion.ts             ตัวตรวจจับ motion ที่ทดสอบแยกได้
src/hooks/use-motion.ts        สิทธิ์ การตั้งค่า และ sensor subscriptions
tests/game.test.mjs            Regression tests
```

ตรรกะเกมทำงาน 10 Hz โดยไม่ผูกระยะทางกับจำนวนเฟรม ส่วน Reanimated ทำ interpolation ของตำแหน่งบน UI thread มีเฉพาะวัตถุใกล้ผู้เล่นที่ถูก render ถ้าแอปสะดุดเกิน 0.5 วินาทีจะพักแทนการข้ามสิ่งกีดขวาง

## ตรวจสอบ

```powershell
npm run typecheck
npm test
npm run export:web
npx expo export --platform android
npx expo export --platform ios --output-dir dist-ios
```

Tests ครอบคลุมสนาม/ช่วงพัก, ขอบช่อง, เก็บเหรียญครั้งเดียว, กระโดดข้ามแคมป์ไฟ/ชนถังไม้, สิ่งกีดขวาง 3 แบบ, ผู้พันประชิดหลังชนครั้งแรกและแพ้เมื่อชนครั้งที่สอง, เล่นจบทั้ง 6 ฉาก, latch เอียงค้าง/กลับตรงอย่างรวดเร็ว, สลับทิศ, กรองแรงลงพื้น และเอียงไม่เกิด jump

### ทดสอบบนโทรศัพท์ก่อนนำไปสาธิต

- ท่าถือที่ใช้งานจริง: กลับตรง → เอียงซ้าย → ค้าง 3 วินาที → กลับตรง → เอียงซ้ำ ต้องเปลี่ยนครั้งเดียวในแต่ละครั้ง
- กระโดดเบา ๆ 10 ครั้ง เว้นอย่างน้อย 2 วินาที ตรวจจำนวนที่ตรวจจับและการลงพื้นไม่ทำให้กระโดดซ้ำ
- ลองสั่นมือ/เดิน/เอียงตามปกติ ถ้านับเป็นกระโดดบ่อยเลือก “ลดการสั่น”
- ทดลองพัก สลับแอป ปฏิเสธสิทธิ์ และเริ่มใหม่ ตรวจว่าคะแนนไม่เปลี่ยนระหว่างพักและไม่ค้างจากรอบก่อน
- ประเมินจังหวะชน/กระโดดและความลื่นบน Android รุ่นที่ช้าที่สุดที่จะใช้ ความไวและประสิทธิภาพบนอุปกรณ์จริงยังไม่ถือว่าผ่านจากผลทดสอบบนเว็บ

อ้างอิง API: [Accelerometer SDK 57](https://docs.expo.dev/versions/v57.0.0/sdk/accelerometer/) · [Gyroscope SDK 57](https://docs.expo.dev/versions/v57.0.0/sdk/gyroscope/)
